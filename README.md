# Математический и финансовый помощник

Интерактивное веб-приложение на **R** и **Shiny** (`shinydashboard`) для выполнения
математических расчётов, статистического анализа и финансовых вычислений.

---

## ✨ Возможности

### 🧮 Калькулятор
- Вычисление любых математических выражений на языке R
- Поддержка функций `sqrt`, `log`, `exp`, `sin`, `cos`, `tan`, `^` и др.
- Обработка ошибок ввода

### 📐 Математические задачи
- **Квадратное уравнение** `ax² + bx + c = 0` — дискриминант и корни
- **Круг** — площадь и длина окружности
- **Треугольник** — площадь по формуле Герона
- **Факториал** — `n!`
- **Числа Фибоначчи** — первые `n` чисел
- **НОД и НОК** — наибольший общий делитель и наименьшее общее кратное

### 📊 Описательная статистика
- Загрузка данных из CSV или ручной ввод
- Метрики: среднее, медиана, стандартное отклонение, дисперсия,
  минимум, максимум, квартили, асимметрия, эксцесс
- Плитки-индикаторы (`valueBox`) с ключевыми значениями
- **Гистограмма** распределения с отметками среднего и медианы
- **Ящик с усами** (boxplot)

### 🔗 Корреляционный анализ
- Загрузка CSV с двумя и более числовыми столбцами
- Ручной ввод данных в формате `x,y`
- **Матрица корреляций** Пирсона
- **Матрица p-value** для оценки значимости
- **Диаграмма рассеяния** с линией линейной регрессии

### 💰 Финансовые расчёты
- **Сложный процент** — формула `P·(1 + r/m)^(m·t)`
  - Настройка частоты начисления: год, полугодие, квартал, месяц, день
  - График роста капитала, таблица по годам
  - Расчёт прибыли и доходности
- **Аннуитетный платёж** по кредиту
  - Формула `S·i·(1+i)^n / ((1+i)^n − 1)`
  - Ежемесячный платёж, общая сумма выплат, переплата
  - График погашения и таблица остатка долга по месяцам

## ⚙️ Требования

- **R** версии 4.0 или выше
- **RStudio** (рекомендуется)
- Пакеты R:
  - `shiny` ≥ 1.7
  - `shinydashboard` ≥ 0.7
  - `ggplot2` ≥ 3.4
  - `DT` ≥ 0.27
  - `moments` ≥ 0.14

## 📄 Форматы входных данных

### Для раздела «Статистика»

CSV-файл с **одним числовым столбцом**:

```csv
value
12
15
18
20
22
```

Или ввод вручную — числа через запятую:
```
12, 15, 18, 20, 22, 25, 28, 30
```

### Для раздела «Корреляция»

CSV-файл с **двумя и более числовыми столбцами**:

```csv
x,y
1,2
2,4
3,5
4,4
5,7
```

Или ввод вручную — по строке на наблюдение:
```
1,2
2,4
3,5
4,4
5,7
```

Разделитель — запятая или точка с запятой.
